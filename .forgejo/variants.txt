# Release variants for this repository.
#
# Format: <name>|<dockerfile>|<target>|<suffix>|<default>|<KEY=VALUE;…>|<platforms>
# - `alpine` is the default variant: it owns `latest` and the unsuffixed version tags.
# - Every variant also gets a floating tag named after itself (alpine, trixie,
#   alpine-full, trixie-full, alpine-headless, ...).
# - Platforms: linux/amd64 only. The trixie (static ffmpeg) image relies on an
#   amd64-only static ffmpeg build; add arm64 here only after providing an
#   arm64 static ffmpeg (or use the alpine variants for arm64).
#
# 8 variants = {alpine,trixie} x {combined,headless} x {slim,full}
#   combined  = frontend + backend (nginx same-origin proxy)
#   headless  = backend only
#   full      = WITH_EXTRA=1 (ffmpeg + streamlink); slim = WITH_EXTRA=0
